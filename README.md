**Fontos tudnivalók**

Backend mappa  
npm install - telepíti a függőségeket
.env - létre kell hozni egy .env fajlt a repoban megtalálható .env.example mintájára
node . - elindítja a szervert 3000-es porton

Frontend mappa  
npm install - telepíti a függőségeket
npm start - ha megmegnyitja az alkalmazást böngészőben
  
mivel a backend 3000-es porton fut ezért megkérdezi az alkalmazás indítása előtt a terminál, hogy szeretnénk-e másik porton futtatni az app-ot, y-val kell válaszolnunk.
